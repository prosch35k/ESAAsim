# SIM01 pilot transmissions

One file per pilot transmission from the SIM01 audio recording (`../source/ESGG_S1_SIM01_Audio_1.mp3`), in the order of the transcript
(`../source/ESGG_S1_SIM01_Transcript_1.pdf`). The recording only contains the pilots; the ground controller parts are not recorded.
`manifest.json` lists file, callsign, transcript text and the start/end time in the original recording.
